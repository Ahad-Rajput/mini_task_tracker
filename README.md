# mini_task_tracker

A menu-based Python task tracker that stores tasks in a JSON file.

## Features

- Add tasks with a title.
- View tasks and their status.
- Mark tasks as completed.
- Delete tasks.
- Save and load tasks using JSON.
- Handle invalid input and missing files.

## Technologies

- Python
- JSON
- Git and GitHub

## How to Run

1. Make sure Python is installed.
2. Download `main.py`.
3. Open a terminal in the project folder.
4. Run:

   python main.py

The program creates `tasks.json` automatically when tasks are saved.

## Concepts Practiced

Functions, lists, dictionaries, loops, conditions,
exception handling, file handling, and JSON serialization.
